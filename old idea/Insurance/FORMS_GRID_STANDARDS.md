# دليل وقواعد القياسات الشبكية للاستمارات التأمينية (Forms Grid Standards)

هذا الملف مرجع شامل لقواعد وحسابات مساحات الحقول والمربعات في الاستمارات الحكومية (س1، س6، وأي استمارة جديدة يتم إضافتها مستقبلاً).

---

## 1. المعادلة الذهبية لتوسيط الأرقام داخل المربعات (The Golden Centering Formula)

لكل حقل شبكي يحتوي على $N$ خانة (مربع) وعرض إجمالي $W$ بكسل:

$$\text{cellWidth} = \frac{W}{N}$$

**كود الـ CSS الموحد:**
```css
direction: ltr;
text-align: left;
font-family: monospace;
font-size: 16px;
font-weight: bold;
padding: 0px;
letter-spacing: calc(-1ch + [cellWidth]px);
text-indent: calc((-1ch + [cellWidth]px) / 2);
```

### شرح المعادلة:
- `letter-spacing`: تجعل كل رقم يمتد بمقدار عرض المربع الواحد تماماً.
- `text-indent`: تدفع أول رقم إلى **المنتصف الهندسي الدقيق** للمربع الأول، وبالتالي تقع جميع الأرقام التالية في منتصف كل مربع بالمليمتر.

## 5. خطوات إضافة أي استمارة جديدة بسهولة
1. تحديد موضع المستطيل في الاستمارة الجديدة (`top`, `right`, `width`, `height`).
2. تحديد نوع الحقل وعدد خاناته (مثلاً: رقم قومي = 14، رقم تأميني = 9).
3. تطبيق المعادلة مباشرة:
   - $\text{cellWidth} = \text{width} / N$
   - `letter-spacing: calc(-1ch + [cellWidth]px);`
   - `text-indent: calc((-1ch + [cellWidth]px) / 2);`
4. النتيجة: توسيط فوري مباشر بنسبة 100% دون الحاجة للتجربة والخطأ.
