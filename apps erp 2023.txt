Architectural Inventory & Codebase Dissection: APPS ERP Application 2023
This technical audit provides a recursive, deep-level architectural dissection of the APPS ERP Application 2023 system. The analysis is based on static reflection of the compiled binaries, schema extraction from the active Microsoft SQL Server instance (Tarabot_Data_2023), local configuration databases (Profile\Data.mdb), Crystal Reports report definitions, and deployment orchestration assets.

Phase 1: Directory Tree & Ecosystem Inventory
1.1 Architectural Ecosystem Overview
The application is a classic two-tier client-server enterprise Windows Forms ERP developed in Visual Basic .NET targeting the .NET Framework 3.5 (CLR 2.0/3.5, 32-bit x86). The runtime leverages Telerik RadControls for WinForms (v2010.3.10.1109) for UI presentation, SAP Crystal Reports .NET Runtime (v13.0.2000.0) for business intelligence reporting, and Microsoft Jet 4.0 / ACE OLEDB for local encrypted node configuration.

2.1 Application Architecture & Startup Sequence
Entry Point: The application starts via Apps_Application_2017.My.MyApplication (WindowsFormsApplicationBase), launching 

Login
 as the startup form.
Local Configuration Reading:
Login_Load constructs an OLEDB connection to Profile\Data.mdb using password awlad mosa.
Queries Profile_User: extracts Server_Name, Data_Name, Data_User, Data_Password, and Activation_Code.
If Server_Name or Data_Name is empty, the application redirects immediately to 

Data_Form
.
Hardware Binding Enforcement:
Login.CpuId() queries WMI class Win32_Processor to retrieve the machine's hardware processor ID.
It computes the mathematical token verification formula: $$\text{TargetID} = \frac{\frac{\text{Val}(\text{Activation_Code})}{41.0} + 864864864}{321.0} - 1111111110$$
If TargetID does not equal the CPU Hardware ID, the system locks execution and displays Data_Form to prompt for an activation key.
SQL Handshake & Authentication:
Establishes persistent connection Conn.MdF_Conn to SQL Server: Data Source=<Server_Name>;Initial Catalog=<Data_Name>;User ID=<Data_User>;Password=<Data_Password>
Authenticates entered User_ID and User_Pin against dbo.Users.
Queries the 58 RBAC columns of dbo.Users.
Caches active user credentials in Profile\Data.mdb -> Users_Table.
Dashboard Transition:
Opens 

ControlPanel
 (MDI Shell).
Loops through all UI navigation buttons (RadButton), setting Visible = True/False based on the operator's permission flags in dbo.Users.

public String ToBase64(): Concatenates all 5 TLV byte arrays and converts them into a Base64 string for QR matrix encoding via MessagingToolkit.QRCode.

public String ConvertToEnglish(): Produces standard English currency strings.

3.3 Relational View Architecture (239 Views)
Rather than executing stored procedures, APPS ERP 2023 executes parameterized SELECT queries against a comprehensive layer of 239 SQL Server Views.

Key analytical views include:

Level5_View: Joins Level5 -> Level4 -> Level3 -> Level2 -> Level1. Denormalizes the complete 5-tier Chart of Accounts tree into every row, attaching Balance_Sheet_Type, Incom_Type, Module_Type, and Account_Nature.
Items_With_Balance_View: Computes live stock on hand by joining Items with Items_Details across specific Inventory_ID warehouse partitions.
Sales_R_Details_View1: Combines line items, item masters, units, currency rates, warehouse codes, and stock movement multipliers into a unified view for profitability analysis.
GeneralLedger_View: Blends GeneralLedger_Head and GeneralLedger_Details with Level5_View, Costcenters_View, and Currencies for real-time Trial Balance and Ledger generation.

4.2 Critical Architectural Findings for Modern Web ERP Migration
Decouple Business Logic from UI:
In the legacy desktop app, business calculations (FIFO/Weighted Average cost updating, tax calculations, and double-entry balancing) are executed in WinForms UI event handlers (Save_Click, Qty_TextChanged).
Modern Architecture: Must be migrated into a stateless TypeScript/Node.js or .NET Core Web API service layer with automated database transactions (BEGIN TRAN ... COMMIT).
Eliminate Client-Side Plaintext Security:
Profile\Data.mdb stores SQL credentials and dbo.Users stores authentication PINs in plaintext.
Modern Architecture: Implement secure hashing (Argon2id/bcrypt) and JWT/OAuth2 Bearer tokens with Role-Based Access Control (RBAC) reflecting the 58 granular permissions.
Database View Preservation:
The 239 SQL Server views in Tarabot_Data_2023 represent clean denormalizations of accounting hierarchies and stock balances.
Modern Architecture: These views can be preserved or directly mapped via an ORM (e.g., Prisma, Drizzle, or Entity Framework Core) as database read-models.
ZATCA & Reporting Engine Migration:
TLVCls.vb logic can be implemented as a lightweight utility module in modern TypeScript/Python.
The 164 Crystal Reports (.rpt) should be transitioned to modern web-native reporting frameworks (e.g., headless PDF rendering with @react-pdf/renderer or Puppeteer HTML-to-PDF).
